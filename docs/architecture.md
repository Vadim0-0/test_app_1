# Архитектура приложения

Код сгруппирован по функциям в `lib/features`: `home`, `notes`, `weather`,
`gallery`, `todos`, `quotes`, `converter`, `counter`.

## Запуск и общий код

- `lib/main.dart` запускает приложение.
- `lib/app/app.dart` содержит `MyApp`, тему и `MaterialApp`.
- `lib/features/home/home_screen.dart` содержит главное меню.
- `lib/shared/widgets/animated_dropdown.dart` используется редактором заметок
  и конвертером. Общие компоненты не зависят от отдельных функций приложения.

## Обязанности папок

| Папка | Содержание |
| --- | --- |
| `models` | Данные и преобразование JSON |
| `data` | Получение данных из сети, файлов и локального хранилища |
| `controllers` | Состояние и операции над данными |
| `screens` | Компоновка экранов, навигация и уведомления |
| `widgets` | Отдельные элементы интерфейса |
| `dialogs` | Диалоги, нижние панели и открытие меню |

Создавать каждую папку для каждой функции необязательно. Например, счётчику
пока достаточно одного экрана.

## Заметки

`NotesScreen` владеет `NotesController`, подписывается на его изменения и
освобождает его в `dispose`. Контроллер получает `NotesStorage` через
конструктор; в тестах вместо него используется хранилище в памяти.

Контроллер загружает данные, сохраняет заметки и категории, проверяет дубликаты,
фильтрует заметки и обрабатывает удаление категории. Методы изменения возвращают
`NotesSaveResult`. Экран выбирает уведомление по результату операции.

Списки обновляются только после успешной записи. Имена ключей хранилища и формат
JSON при реорганизации не менялись.

Экран хранит состояние раскрытия карточек и ID карточки, скрытой во время меню.
Это состояние отображения, которое не требуется сохранять на устройстве.

- `NoteCard` — оформление карточки и обработка нажатий.
- `NoteContent` — общий заголовок и текст для карточки и анимированного меню.
- `NoteCategoryBar` — выбор категории и вызовы добавления/редактирования.
- `NoteFocusMenu` — анимированное отображение карточки и действий.
- `showNoteFocusMenu` — измерение карточки и маршрут меню; ждёт `route.completed`
  перед возвращением результата.
- `NoteEditorScreen` — форма, которая возвращает `Note`, не записывая хранилище.
- Диалоги удаления возвращают решение пользователя; запись выполняет контроллер.

## Погода

`WeatherController` управляет поиском, избранным, повторными запросами и
обновлением погоды. `WeatherService` получает данные, а
`FavoriteCitiesStorage` сохраняет список избранных городов.

Номер версии поиска позволяет игнорировать устаревшие ответы после изменения
ввода. Сохранённые `Future` предотвращают повторные запросы при перестроениях.
Избранные города сохраняются постоянно; запросы погоды живут в памяти контроллера.

`WeatherScreen` содержит навигацию, уведомления и выбор состояния содержимого.
`WeatherSearchField` содержит поле ввода; `city_actions_sheet.dart` — нижнюю панель.
Карточка, график и подробности погоды остаются отдельными виджетами.

## Другие функции

- Галерея: экраны, `PhotoStorage`, модель фото, `PhotoCard` и диалог удаления.
  Управление overlay меню удаления пока остаётся в `GalleryScreen`.
- Задачи: модель `Todo` и чтение/запись `TodosStorage` отделены от экрана.
- Цитаты: модель `Quote` и чтение ассета `QuotesLoader` отделены от экрана.
- Конвертер: модель `Conversion` и список формул отделены от экрана.

## Как добавлять код

1. Найти функцию приложения в `features`.
2. Описать новые данные в `models`, если они нужны.
3. Чтение/запись поместить в `data`.
4. Операции над состоянием добавлять в существующий контроллер.
5. Виджетам передавать данные и callbacks; не обращаться из карточек к хранилищу.
6. Контроллеры не должны хранить `BuildContext` или открывать диалоги.
7. Внутри `lib` использовать относительные импорты (`../models/...`).
   В тестах использовать `package:test_app_1/...` для доступа к коду из `lib`.

Не нужно выделять отдельный файл для каждого небольшого метода. Разделение
полезно, когда часть имеет собственную понятную задачу или используется повторно.

## Проверка

```sh
flutter analyze
flutter test
```

Тесты контроллеров проверяют удаление категории с сохранением/удалением заметок,
ошибку сохранения, дубликаты категорий, устаревшие ответы поиска и запись избранного.
Тест главного экрана проверяет наличие пункта погоды.

На устройстве дополнительно проверить редактирование заметок, долгое нажатие
и обратную анимацию меню, фотографии, поиск и обновление погоды.
