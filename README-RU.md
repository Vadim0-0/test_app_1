# Flutter Practice App

Учебный проект на Flutter, объединяющий несколько мини-приложений в одном интерфейсе.

[English version](README.md)

## Возможности

- **Счётчик** — изменение значения с историей действий.
- **Конвертер единиц** — перевод значений между разными единицами измерения.
- **Список задач** — управление задачами с локальным сохранением.
- **Случайные цитаты** — показ цитат из локального JSON-файла.
- **Фотогалерея** — добавление, просмотр и удаление фотографий с локальным хранением.
- **Погода** — поиск городов, текущая погода, прогноз на семь дней и графики температуры.

## Технологии

- Flutter и Dart
- Shared Preferences для локального сохранения данных
- Image Picker для выбора фотографий
- Path Provider и Path для работы с локальными файлами
- HTTP для запросов погоды и поиска городов через Open-Meteo
- FL Chart для графиков температуры
- Intl для форматирования дат
- Flutter Dotenv для загрузки файла окружения

## Запуск проекта

### Требования

- Flutter SDK, совместимый с Dart `^3.13.3`
- Настроенный эмулятор или подключённое устройство
- Доступ к интернету для загрузки погоды и поиска городов

### Установка

1. Клонируйте репозиторий и перейдите в его папку.
2. Установите зависимости:

   ```bash
   flutter pub get
   ```

3. Создайте файл окружения:

   ```bash
   cp .env.example .env
   ```

   Текущий сервис погоды не требует API-ключа. Файл `.env` можно оставить пустым. Он должен существовать, поскольку приложение загружает его при запуске.

4. Запустите приложение:

   ```bash
   flutter run
   ```
